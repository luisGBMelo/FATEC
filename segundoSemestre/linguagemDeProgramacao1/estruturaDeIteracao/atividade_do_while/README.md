# Atividade: Media de idades usando `do while`

Repositório dedicado à resolução da atividade sobre **[Estruturas de Iteração]** na linguagem **C**.

## 📝 Descrição do Problema
"Um programa que calcule a media das idades de n pessoas. O programa deve ser finalizado quando for digitado -1"

## 🛠️ Tecnologias e Conceitos Utilizados
* Linguagem: **[C]**
* Estruturas de controle: `if/else, while`
* Entrada e Saída de dados: `printf/scanf`
* Verificação de entrada com limpeza de buffer: `getchar`

## 🚀 Como Compilar e Executar no Linux

Certifique-se de ter o pacote `build-essential` instalado em sua distribuição Linux.

1. Abra o terminal na pasta onde o arquivo está salvo.
2. Compile o código executando o comando abaixo:
   ```bash
   [g++ ou gcc] nome_do_arquivo.[cpp ou c] -o programa
   ```
3. Execute o programa gerado:
   ```bash
   ./programa
   ```

## 💻 Exemplo de Execução

```text
Media das idades em while
Para encerrar o programa digite -1
 Digite uma idade: 3
 Digite uma idade: 4
 Digite uma idade: 6
 Digite uma idade: -1
A media de 3 pessoas eh: 4.33
```
