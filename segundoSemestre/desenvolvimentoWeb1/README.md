# 💻 Desenvolvimento WEB

Repositório central de estudos para a disciplina de Desenvolvimento WEB. Aqui aplico conceitos teóricos em código prático utilizando HTML5 e CSS3.

## 🧬 Ementa e Conteúdos Aprendidos
* **Estrutura Básica HTML5:** Configuração do documento (`<!DOCTYPE html>`, `<html>`, `<head>`, `<body>`).
* **Elementos de Texto:** Marcação de parágrafos (`<p>`) e hierarquia de títulos (`<h1>` até `<h6>`).
* **Mídias e Hiperlinks:** Inserção de imagens (`<img>`) e links (`<a>`) locais, internos e externos.
* **Organização de Dados:** Criação de listas (ordenadas e não ordenadas) e tabelas (`<table>`, `<tr>`, `<td>`, `<th>`).
* **Estilização com CSS:** Aplicação de estilos de forma Inline, Interna (`<style>`) e Externa (arquivo `.css`).

## 📂 Organização das Atividades
* [Atividade 01 - Estrutura e Textos](atividade-textos/): Exercício prático utilizando tags de texto, títulos e css inline.
* [Atividade 02 - Listas e Tabelas](atividade-tabelas/): Exercício prático com tabelas e listas organizadas.
* [Atividade 03 - Estilização CSS](atividade-css/): Exercício prático aplicando CSS externo e interno.
